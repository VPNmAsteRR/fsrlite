# fsrlite

Оверлейный апскейлер/шарпен для оконных игр. Захватывает окно игры через Windows Graphics Capture, прогоняет кадр через два шейдерных прохода (edge-aware upscale + contrast-adaptive sharpen) и рисует результат в click-through окне поверх монитора. Игра не патчится и не знает о туле — инжекта нет, античит не трогаем.

## Как строится выигрыш

Важно понимать схему: **скорость даёт не тул, а разрешение, в котором рендерит игра.** Поставь в игре разрешение/масштаб ниже (например 1280x720 в окне на 1920x1080 мониторе), и fsrlite растянет кадр до нативного с шарпеном. Если игра уже рендерит в нативе — тул только добавит шарп, прироста FPS не будет (и даже просядет на пару кадров из-за захвата).

Соотношение сторон сохраняется: кадр вписывается по letterbox/pillarbox, не растягивается.

## Сборка (Windows)

Нужен MSVC 2022 + Windows SDK 10.0.19041+ (в нём же лежат заголовки C++/WinRT).

```bat
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Выход: `build\Release\fsrlite.exe` и `build\Release\shaders\upscale.hlsl` (шейдер компилируется в рантайме, держи его рядом с exe в подпапке `shaders`).

## Запуск

1. Игра — в **borderless windowed** (эксклюзивный fullscreen захват не отдаст).
2. Запусти игру, потом:

```bat
fsrlite.exe "Roblox" 0.8
```

Первый аргумент — подстрока заголовка окна, второй — сила шарпена 0..2.

Хоткеи:

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+Q` | выход |
| `Ctrl+Alt+S` | шарпен: 0.0 → 0.5 → 1.0 → 1.5 → 0.0 |
| `Ctrl+Alt+U` | bypass: сравнить с апскейлом вкл/выкл |

Оверлей накрывает монитор, на котором висит игра, и переезжает за ней при смене монитора (проверка каждые 250 мс). При закрытии игры выходит сам.

## Как это устроено

- `src/main.cpp` — окно-оверлей (`WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOPMOST`), WGC-сессия, letterbox-вьюпорт, хоткеи, свопчейн, мьютекс на D3D-контекст (кадры приходят с другого потока).
- `src/upscaler.cpp` — два fullscreen-прохода: EASU (12 тапов, Lanczos2 + билатеральный вес по яркости) в промежуточный таргет размером с вьюпорт, затем RCAS (крестовый unsharp с демпфированием по локальному контрасту).
- `shaders/upscale.hlsl` — сами шейдеры плюс `PSCopy` для bypass, компилируются `D3DCompileFromFile` при старте.
- `src/fsrlite.h` — интерфейсы.

Алгоритмы — самостоятельная реализация в духе FSR1 (EASU/RCAS), не копия исходников AMD. FSR1 сам по себе открыт под MIT, если нужна эталонная версия — она на GPUOpen.

## Ограничения, о которых лучше знать сразу

- Требуется Windows 10 1903+ (WGC). На Win7/8 не пойдёт.
- Захват идёт через композитор: латентность +1..2 кадра относительно инжект-хуков. Для синглов и казуалки незаметно, для соревновательных шутеров — ощутимо.
- HDR-игры: формат захвата BGRA8, HDR будет выглядеть пересвеченным. Нужен отдельный float16-путь.
- Exclusive fullscreen, DRM-защищённые окна и часть лаунчеров WGC не отдаёт.
- Курсор в кадр не попадает (`IsCursorCaptureEnabled(false)`); включи `true`, если нужен, но тогда он рисуется дважды.
- Клики проходят сквозь оверлей в игру, но координаты мыши остаются в системе игры — если игра получает мышь по абсолютным координатам окна, курсор может смещаться при letterbox.

## У тебя Linux

Windows-бинарник тебе тут не нужен: **gamescope** делает ровно это из коробки, включая FSR1/FSR2 и шарпен.

```bash
# Roblox через Sober, апскейл до 1920x1080 с FSR
gamescope -W 1920 -H 1080 -w 1280 -h 720 -F fsr --sharpness 4 \
    -- flatpak run org.vinegarhq.Sober
```

- `-w/-h` — внутреннее разрешение (его рендерит игра), `-W/-H` — итоговое.
- `-F fsr` — фильтр апскейла (`linear`, `nearest`, `fsr`, `nis`, `pixel`, `sgsr`).
- `--sharpness 0..20` — шарпен, **0 = максимум**, 20 = выключен.
- `-S fit` — тип скейлера (`auto`, `integer`, `fit`, `fill`, `stretch`), не путать с фильтром.
- `--force-grab-cursor` — если мышь уезжает.
- `-f` — фуллскрин, `-b` — бордерлесс.

Это тот же принцип, что в fsrlite, но уже отлаженный и с нормальным композитором.

## Лицензии

DLSS переписать нельзя — закрытый NGX SDK, веса моделей не поставляются. Всё, что называют «DLSS для всех» — это FSR/XeSS. FSR1 — MIT (GPUOpen), можно брать исходники и встраивать легально. Код fsrlite — твой, делай что хочешь.
